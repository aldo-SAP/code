eDocument Status Checker

Paste a status string and see whether it satisfies the configured flag rules. Change a flag's rule with the radio buttons to test other configurations.

    Update the configuration from the SAP tables
    1. Copy all rows of EDOPROCFLAGASG (columns PROCESS PROC_VERSION STAT_POS STAT_FLAG) into the left box.
    2. Copy all rows of EDOPROCSTAFLAGT (columns PROCESS FLAG description) into the right box.
    3. Press Apply pasted tables and read the messages below.
    4. Press Save config JSON and choose your existing data/edoc_flag_config.json to overwrite it (use Open config JSON… first and Save writes straight back into the same file).
    X = flag set  ·  o (also 0 _ - . or blank) = flag not set
    + = mandatory  ·  - = empty  ·  o = optional
    Mandatory = must be X · Empty = must not be set · Optional = anything
