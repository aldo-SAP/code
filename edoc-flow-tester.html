Replay the process steps of EDOPROCSETFLAG one after another and watch the status string change. Pick a step, press it, and compare the result with what you expect.

Add / update steps from the SAP tables EDOPROCSETFLAG and EDOPROCCHKFLAG
  1. Copy the rows of each table into its box (tab-separated, empty cells allowed). Variants may be empty.
  2. Press Apply pasted rows. A row with the same key replaces the earlier one; everything else is kept.
  3. Press Save steps JSON and choose edoc_setflag_config.json to overwrite it. The file holds both tables, so Open steps JSON… brings them back later.
