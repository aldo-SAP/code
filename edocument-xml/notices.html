Third-party sources and licences

The eDocument XML Viewer is a small internal helper tool, not a product. It checks UBL, FatturaPA and the related XML files against the published rules of each country. The checking code, the viewer and the sample invoices are original work (the samples contain invented data only). The rules, schemas and fonts below belong to their authors. This file says where each comes from, under which licence it is published, and what was changed. If you are an author and want something changed or removed, please open an issue.

What was changed: the Schematron files were converted into data (tests/gen-schematron.py, tests/gen-pint-ae.py) so that a small engine can run them in the browser. The rules (their ids, conditions and messages) are kept as published. English and Italian translations of the messages and the "how to fix" lines were added. The Italian rules were written from the documents named above, together with English wording; the Italian code descriptions are the schema's own text. No text of the AFNOR standard itself is included.

The viewer's own checks (FR-CHK-*, CHK-*, the structure rules UBL-XSD-* and IT-XSD-*, IT-SPEC-*) are not part of any official rule set and are marked as such.
