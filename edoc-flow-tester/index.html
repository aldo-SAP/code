Replay eDocument process steps and watch the status string change. A step may run only if one of its EDOPROCCHKFLAG sequences matches the current status; that sequence's method variant picks the EDOPROCSETFLAG row that sets and clears the flags.

SAP tables & files – paste EDOPROCSETFLAG / EDOPROCCHKFLAG or open your saved JSON files

The steps file edoc_setflag_config.json holds both tables. Open your saved copy to bring them back; Save steps JSON then writes into that same file (Chrome / Edge).

Flag names and rules come from edoc_flag_config.json (the Status Checker's file). It is loaded from the site automatically; open it here when the page runs from disk.

1 · Choose the next step

Each EDOPROCCHKFLAG row (step / variant / sequence) is its own choice: checked against the current status, then its method variant's EDOPROCSETFLAG row is applied.

2 · Current status

Green outline = set by the last step · orange outline = cleared by the last step · red border = rule violated.

3 · Steps taken & expected result

Type what you expect after each step: X (or +) = set, o = not set, ? = don't care. Missing characters count as not set.

4 · Allowed routes

One route per line: the steps a document may take, separated by commas, from an empty status. A step with a variant is written PROC_BLR  ACCEPT (tab or spaces). Every step of every route must pass EDOPROCCHKFLAG. A line always, DISPL_HTML, DOWNLOAD names steps that may run in any status. Lines starting with # are comments. Uses the process selected above.

Route coverage – everything else the tables allow

Your routes say which steps are wanted in which status. The tester tries every step in every status the tables can reach and reports each move they allow that no route uses (a leak), statuses where a document gets stuck, and rows that are never used. No negative tests to write: anything not in a route is reported.

5 · Rule check of the current status

Uses the Mandatory / Optional / Empty rules from edoc_flag_config.json (same as the Status Checker page). It is normal for this to fail while the flow is only half-way through.
